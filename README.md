## Brain Tumor Detection (YOLOv8)

Fine-tuned a pretrained YOLOv8 object detection model to locate and classify brain tumors in MRI scans, drawing a bounding box around each tumor with its predicted type and confidence.

**Stack:** Python, PyTorch, Ultralytics YOLOv8
